# Music

Add your MP3 here (for example `track.mp3`) and set `local` in
`assets/js/config.js` to `assets/audio/track.mp3`.

To use a hosted MP3, leave `local` blank and paste the complete HTTPS address
into `remote`. The host must allow cross-origin media playback.

Only publish audio you own or have permission to use. MP3 files are ignored by
default; remove `assets/audio/*.mp3` from `.gitignore` to commit one.
